# Street IO - Agent Guidelines & Project Instructions

## Project Overview
**Street IO** is a pay-to-access article blog platform where users pay to unlock and read information and investigative journalism that might otherwise be deemed too controversial or sensitive for mainstream media outlets.

## Core Development Rules
1. **Step-by-Step, Component-by-Component**:
   - Build strictly one step and one component at a time.
   - Do NOT build anything ahead of the immediate task assigned.
   - Do NOT scaffold future components, pages, or features without explicit instruction.
2. **No Tailwind CSS**:
   - Tailwind CSS is strictly prohibited.
   - Use SCSS / Vanilla CSS / CSS Modules (SCSS is configured in this project).
3. **No Unnecessary Terminal Commands**:
   - Do NOT run commands or logs in CMD/PowerShell unless strictly necessary.
4. **Focused Scope**:
   - Focus 100% on the exact task directly in front of you.
